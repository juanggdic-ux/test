# Raw input data

`synthetic_demo.zip` contains **artificial** signals provided so the code can run and be tested without access to the real RAVDESS dataset. It is not evidence about emotion recognition or depression.

To use RAVDESS, download the `Audio_Speech_Actors_01-24.zip` archive from the official dataset record and place it here, **without adding it to GitHub**. Then run `python run_pipeline.py --zip data/raw/Audio_Speech_Actors_01-24.zip --actors 24` from the repository root.
